# Web Scraping Ethics and Legality Guidelines

แนวปฏิบัติด้านจริยธรรมและกฎหมายที่ใช้ในการพัฒนา Agentic Web Scraper นี้

## 1. เคารพ `robots.txt`
ตรวจสอบ `https://[domain]/robots.txt` ก่อนเสมอ หากไม่อนุญาตให้เข้าถึง path ใด **ห้าม scrape path นั้น**
(โปรเจกต์นี้ใช้ `books.toscrape.com` ซึ่งเป็น sandbox ที่สร้างไว้สำหรับฝึก scraping โดยเฉพาะ)

## 2. อ่าน Terms of Service (ToS)
หาก ToS ห้าม scraping การฝ่าฝืนถือเป็นการผิดสัญญา และการที่ไม่มีข้อห้ามก็ไม่ได้แปลว่าอนุญาตโดยอัตโนมัติ

## 3. Rate Limiting และการหน่วงเวลา
ส่ง request ถี่เกินไปอาจถูกมองว่าเป็น DoS — โปรเจกต์นี้หน่วงเวลาระหว่างหน้า (`delay_between_pages`)
และจำกัดจำนวนหน้า (`max_pages`) ผ่านไฟล์ config และไม่ส่ง request พร้อมกันหลายตัว

## 4. ระบุตัวตน (User-Agent)
ควรใช้ User-Agent ที่สื่อความหมาย และไม่ปลอมตัวเป็น bot ของบริการอื่น (เช่น Googlebot)

## 5. ไม่แอบแฝงหรือหลบเลี่ยงอย่างไม่เหมาะสม
เทคนิค anti-blocking (headless, retry, delay) ใช้เพื่อความเสถียรของโปรแกรม ไม่ใช่เพื่อหลบเลี่ยงการป้องกันของเว็บไซต์

## 6. ลิขสิทธิ์และการใช้ข้อมูล
ข้อมูลที่ scrape มามักมีลิขสิทธิ์ ห้ามนำไปเผยแพร่ซ้ำหรือใช้เชิงพาณิชย์โดยไม่ได้รับอนุญาต

## 7. ความเสี่ยงทางกฎหมาย
การ scrape อาจผิดกฎหมายเมื่อผิด ToS, เข้าถึงระบบโดยไม่ได้รับอนุญาตจนก่อความเสียหาย,
ละเมิดลิขสิทธิ์ หรือเก็บข้อมูลส่วนบุคคล (PII) โดยไม่ได้รับความยินยอม (เช่น PDPA)

**สรุป:** ทำอย่างรับผิดชอบ เคารพเจ้าของเว็บไซต์ และขออนุญาตเมื่อไม่แน่ใจ
