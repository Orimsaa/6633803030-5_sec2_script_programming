## 1. โครงสร้างข้อมูลแบบรายการ (Lists)

List คือโครงสร้างข้อมูลเชิงลำดับ (Sequential Data Structure) ที่สามารถจัดเก็บข้อมูลหลายประเภทไว้ในตัวแปรเดียว โดยมีคุณลักษณะสำคัญคือ ความสามารถในการเปลี่ยนแปลงค่าภายในได้ (Mutable) และจัดเก็บข้อมูลที่ซ้ำกันได้

### 1.1 การเข้าถึงและการอ้างอิงตำแหน่ง (Indexing and Slicing)
- สมาชิกภายใน List มีการอ้างอิงตำแหน่งด้วยดัชนี (Index) เริ่มต้นจาก 0 จากซ้ายไปขวา และ -1 จากขวาไปซ้าย
- การตัดแบ่งข้อมูล (Slicing) ใช้รูปแบบ `list_name[start:stop:step]`

### 1.2 เมธอดสำหรับการจัดการ List (List Methods)

| ชื่อเมธอด | หน้าที่การทำงาน | ตัวอย่างคำสั่ง | ผลลัพธ์จากการดำเนินการ |
|:---|:---|:---|:---|
| `append(item)` | เพิ่มสมาชิกต่อท้ายรายการ | `lst.append("Alice")` | ต่อเติม `"Alice"` ในตำแหน่งสุดท้าย |
| `insert(index, item)` | แทรกสมาชิกในตำแหน่งที่ระบุ | `lst.insert(0, "Bob")` | แทรก `"Bob"` ไว้ที่ดัชนี 0 |
| `remove(item)` | ลบสมาชิกตัวแรกที่มีค่าตรงกับที่ระบุ | `lst.remove("Alice")` | ลบ `"Alice"` ออกจากรายการ |
| `pop(index)` | ลบและส่งคืนค่าสมาชิกในตำแหน่งที่กำหนด | `lst.pop(0)` | คืนค่าสมาชิกดัชนี 0 และลบออกจาก List |
| `sort()` | เรียงลำดับข้อมูลในตัวเอง (In-place sorting) | `lst.sort()` | จัดเรียงตามอักษรหรือค่าทางตัวเลข |
| `reverse()` | สลับลำดับข้อมูลจากหลังมาหน้า | `lst.reverse()` | กลับทิศทางของรายการใน List |
| `index(item)` | ค้นหาตำแหน่งดัชนีแรกที่พบข้อมูล | `lst.index("Alice")` | ส่งคืนตัวเลขดัชนีที่พบข้อมูล |
| `count(item)` | นับจำนวนความถี่ของข้อมูลที่ปรากฏ | `lst.count("Alice")` | ส่งคืนจำนวนครั้งที่ปรากฏใน List |

```python
# ตัวอย่างการใช้งาน List ในการจัดการข้อมูลรายชื่อ
student_names = []
student_names.append("Somchai")
student_names.append("Wichai")

if "Somchai" in student_names:
    print(f"Somchai found at index: {student_names.index('Somchai')}")
```

## 2. โครงสร้างข้อมูลแบบทูเพิล (Tuples)

Tuple เป็นโครงสร้างข้อมูลเชิงลำดับที่มีคุณลักษณะคล้าย List แต่มีข้อแตกต่างที่สำคัญคือ **ความไม่สามารถเปลี่ยนแปลงค่าภายในหลังจากสร้างขึ้นได้ (Immutable)** ทำให้เหมาะสมกับข้อมูลคงที่ซึ่งไม่ต้องการให้ระบบแก้ไข

### 2.1 การรวมและแยกข้อมูล (Packing and Unpacking)
- **Tuple Packing:** การรวมข้อมูลหลายค่าเข้าด้วยกันเป็นโครงสร้าง Tuple เดียว
- **Tuple Unpacking:** การกระจายสมาชิกใน Tuple ออกไปยังตัวแปรอิสระ

```python
# Tuple Packing
coordinates = (13.7563, 100.5018)

# Tuple Unpacking
latitude, longitude = coordinates
print(f"Latitude: {latitude}, Longitude: {longitude}")
```

### 2.2 การประยุกต์ใช้งานทางคณิตศาสตร์ (Euclidean Distance Calculation)
ในภาคปฏิบัติการ มีการใช้ Tuple ในการแสดงค่าพิกัด 2 มิติ `(x, y)` เพื่อคำนวณหาระยะทางระหว่างจุดสองจุดในระนาบด้วยสูตรคณิตศาสตร์ร่วมกับโมดูล `math`

```python
import math

point_a = (0, 0)
point_b = (3, 4)

distance = math.sqrt((point_b[0] - point_a[0])**2 + (point_b[1] - point_a[1])**2)
print(f"Euclidean Distance: {distance}")  # ผลลัพธ์: 5.0
```

## 3. การเปรียบเทียบเชิงวิเคราะห์ระหว่าง List และ Tuple

| เกณฑ์การเปรียบเทียบ | List | Tuple |
|:---|:---|:---|
| **ไวยากรณ์การสร้าง** | ใช้วงเล็บเหลี่ยม `[ ]` | ใช้วงเล็บกลม `( )` |
| **การปรับเปลี่ยนค่า (Mutability)** | สามารถเพิ่ม ลบ แก้ไขค่าได้ (Mutable) | ไม่สามารถเปลี่ยนแปลงค่าได้ (Immutable) |
| **ประสิทธิภาพหน่วยความจำและเวลา** | ใช้หน่วยความจำมากกว่า และการเข้าถึงช้ากว่า | ใช้หน่วยความจำน้อยกว่า และการเข้าถึงเร็วกว่า |
| **การนำไปประยุกต์ใช้งาน** | ข้อมูลที่มีปริมาณแปรผัน เช่น รายชื่อ, ตะกร้าสินค้า | ข้อมูลคงที่ เช่น พิกัด GPS, ค่าคงที่ระบบ, วันในสัปดาห์ |
