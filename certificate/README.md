## สิ่งที่ได้เรียนรู้

**Python Essentials 1**
- พื้นฐานการเขียนโปรแกรมและการทำงานของ interpreter
- ชนิดข้อมูล ตัวแปร ตัวดำเนินการ และการรับ/แสดงผลข้อมูล
- การควบคุมทิศทางโปรแกรมด้วย `if` และลูป `for` / `while`
- List, Tuple และ Dictionary
- การเขียนฟังก์ชัน และการจัดการ Exception เบื้องต้น

**Python Essentials 2**
- Module และ Package รวมถึงการใช้ `pip`
- การจัดการ Exception แบบละเอียด
- การทำงานกับ String และ Character Encoding
- การเขียนโปรแกรมเชิงวัตถุ (OOP): Class, Inheritance, Polymorphism
- Generator, Iterator, Closure และ Lambda
- การอ่าน/เขียนไฟล์ (File I/O)
- โมดูลมาตรฐานอย่าง `os`, `datetime`, `time` และ `calendar`

ความรู้จาก certificate ทั้งสองใบช่วยเสริมงานในรายวิชาได้โดยตรง
- เรื่อง OOP ใช้ใน Task Manager แบบ OOP
- เรื่อง File I/O และ Exception ใช้ในงาน automation ทุก Lab ที่ต้องอ่าน/เขียนไฟล์และรับมือข้อผิดพลาด
